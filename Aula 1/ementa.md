## 📚 Ementa

A disciplina aborda os seguintes tópicos principais:

- Conceitos Básicos de Mineração de Dados
- Descoberta de Conhecimento em Banco de Dados (KDD)
- Pré‑processamento de dados: Extract, Transform and Load (ETL), limpeza, transformação, redução de dimensionalidade
- Raspagem de dados (web scraping)
- Técnicas de amostragem e balanceamento de classes
- Técnicas de visualização de dados
- Análise descritiva de dados
- Análise de redes sociais
- Business Intelligence
